# Bot Authentication (Step 2: Agentic Bot Players)

## Problem
Each bot needs a valid JWT token to create/join rooms. The normal auth flow is magic link email → verify → JWT. For bots, we skip the email verification step and generate tokens directly.

## Approach
The `bot-auth.ts` module provides utilities to:
1. Create or retrieve bot users in the DB using direct SQL (bypassing normal user creation flow)
2. Generate JWT tokens for them using `jwt.sign()` with the server's JWT secret
3. Return credentials `{ userId, playerId, token, displayName }` for each bot

## Bot Users
The module creates 3 bot users with fixed credentials:
- `bot1@7kasif.local` / "Bot Alice" → playerId `user_1` (or assigned ID)
- `bot2@7kasif.local` / "Bot Bob" → playerId `user_2` (or assigned ID)
- `bot3@7kasif.local` / "Bot Charlie" → playerId `user_3` (or assigned ID)

## Usage Example
```typescript
import { createBotCredentials } from './bot-auth.js';

const bots = await createBotCredentials();
// bots = [
//   { userId: 1, playerId: 'user_1', token: 'eyJhbGc...', displayName: 'Bot Alice' },
//   { userId: 2, playerId: 'user_2', token: 'eyJhbGc...', displayName: 'Bot Bob' },
//   { userId: 3, playerId: 'user_3', token: 'eyJhbGc...', displayName: 'Bot Charlie' },
// ]

// Use the token to authenticate bot in game API calls
const response = await fetch('/api/room/create', {
  headers: { Authorization: `Bearer ${bots[0].token}` }
});
```

## Testing
Tokens generated by `ensureBotUser()` can be verified using `verifyToken()` from `packages/server/src/auth/auth.ts`:
```typescript
import { verifyToken } from '../auth/auth.js';

const creds = await ensureBotUser('bot1@7kasif.local', 'Bot Alice');
const decoded = verifyToken(creds.token);
// decoded = { userId: 1, email: 'bot1@7kasif.local', role: 'player' }
```

Tokens are valid for 7 days (sufficient for automated test scenarios).

## Notes
- **Idempotent**: Calling `createBotCredentials()` multiple times returns the same users (upsert via email)
- **No email verification**: Bots skip magic-link flow entirely
- **Same JWT secret**: Uses the same `JWT_SECRET` as human users
- **DB-backed**: Bot users are real DB records, can participate in normal gameplay
